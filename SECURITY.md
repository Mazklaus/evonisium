# Sécurité

## Versions suivies

Evonisium est en développement ; seule la branche `main` reçoit des corrections.

## Signaler une faille

Ne publie pas de faille dans une issue publique. Utilise le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**. Décris le problème, comment le reproduire et son impact possible.

Tu recevras une réponse dès que possible ; le projet étant maintenu par une seule personne, aucun délai n'est garanti.

Sont notamment concernés : le chargement de points de sauvegarde ou de fichiers malformés, l'extension Godot (`evo-godot`) et la chaîne d'intégration continue.
