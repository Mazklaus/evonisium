# Contribuer

Merci de ton intérêt pour Evonisium !

Le projet est publié sous licence « tous droits réservés » (voir [LICENSE](LICENSE)) et développé par une seule personne. **Les contributions de code extérieures ne sont pas acceptées pour l'instant** : les pull requests venues d'autres comptes seront fermées.

Tu peux en revanche aider beaucoup par les issues :

- **Signaler un bug** : décris ce que tu as fait, ce que tu attendais, ce qui s'est passé, avec ton système, la graine de la partie et, si possible, le point de sauvegarde.
- **Proposer une idée** : mécanique d'évolution, réalisme scientifique, interface, rendu. Les remarques appuyées sur des sources scientifiques sont particulièrement utiles.
- **Poser une question** sur le fonctionnement de la simulation.

Utilise les modèles proposés à l'ouverture d'une issue. Avant d'en ouvrir une, vérifie qu'elle n'existe pas déjà.

Les failles de sécurité ne se signalent pas dans une issue publique : voir [SECURITY.md](SECURITY.md).

Toute participation est soumise au [code de conduite](CODE_OF_CONDUCT.md).
