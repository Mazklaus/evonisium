# Code de conduite

Evonisium est un projet personnel ouvert à la lecture. Les issues et les discussions sont les bienvenues, à condition de rester respectueuses.

## Ce qu'on attend de chacun

- Rester courtois et bienveillant, y compris dans le désaccord.
- Critiquer des idées ou du code, jamais des personnes.
- Accueillir les questions de débutants comme celles d'experts.
- Respecter le temps des autres : messages clairs, sur le sujet.

## Ce qui n'est pas accepté

- Insultes, harcèlement, propos discriminatoires ou sexualisés.
- Attaques personnelles, provocation volontaire, menaces.
- Publication d'informations privées sur autrui sans son accord.
- Spam et publicité.

## Application

Le mainteneur ([@Mazklaus](https://github.com/Mazklaus)) peut modifier ou supprimer tout message contraire à ce code, verrouiller une discussion et bloquer un compte, temporairement ou définitivement.

Pour signaler un comportement, utilise la fonction « Report content » de GitHub ou mentionne le mainteneur dans une issue. Les signalements sont traités avec discrétion.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
